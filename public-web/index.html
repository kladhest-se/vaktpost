Vaktpost is an iOS app for watching the state of a pfSense firewall — clients, interfaces, gateways, tunnels, certificates, logs — in a form you can take in from a phone screen. It is open source and free.

Set it up Read the source

Needs pfSense CE or Plus and an account on the firewall. Nothing to install on it. iOS 17 or later.

What it shows

Everything is assembled from what pfSense already knows, with the joins and thresholds done on the phone.

Clients, in one list

DHCP leases, the ARP table and static mappings joined into one searchable list, each device named the way the network names it.

Throughput, live

Per-interface rates derived from the firewall's counters, with a full-screen graph that samples every two seconds while you watch it.

Alerts worth waking up for

Gateways, services, capacity, certificates, updates and stale dynamic DNS. Acknowledge one or silence a whole kind.

Tunnels

OpenVPN, WireGuard and IPsec on their own tabs, with connected peers under each instance.

Rules you can actually read

Rules by interface, named the way you named them. NAT port forwards, and aliases with their members expanded.

More than one firewall

Each with its own credentials, TLS settings and refresh interval. Switching is one tap.

Services behind the firewall

HAProxy frontends and backends with their health-check state, and ACME certificates shown next to what they issued.

All four flavours

Latte, Frappé, Macchiato and Mocha with all fourteen Catppuccin accents. The picker above is the same set.

A home screen widget

Small and medium. Health, gateway latency, interfaces up and uplink rate, with the age of the reading.

Setting it up

Nothing to install on the firewall. Vaktpost talks to pfSense's built-in XML-RPC service, so setup is an account and a certificate.

  1. Set System → Advanced → Admin Access → Max Processes to 5 or more. XML-RPC competes with the webConfigurator for PHP workers, and the default leaves too few.

  2. Create a user under System → User Manager and give it the System - HA node sync privilege — the one that makes XML-RPC work. Use a dedicated account rather than your own login: it is administrator-equivalent, and the password is stored on the phone.

  3. Open Vaktpost, enter the firewall address, that username and its password.

  4. Pin the certificate. pfSense ships a self-signed one, so connect once with untrusted TLS allowed, then tap Pin last seen certificate in the firewall's settings. After that the connection is accepted only if that exact certificate is presented. Re-pin when you renew it.

What each screen shows

Overview

Health at a glance: CPU, memory, per-filesystem usage, load, temperature, uptime, the state table and every gateway. Pin the interfaces you care about and they sit at the top.

Clients

Every device the firewall knows about, from DHCP leases, ARP and static mappings, with the filter log for each one.

Network

Interfaces with addresses, media, errors and counters. Tap one for a live graph. The ARP table on a second tab.

Logs

Filter, system, authentication, DHCP and OpenVPN, searchable, with pass and block filtering on the filter log.

VPN

OpenVPN, WireGuard and IPsec, each on its own tab, with peers and their transfer under the instance they belong to.

Firewall

Rules by interface, NAT port forwards and aliases with their members resolved.

Certificates

The store sorted by expiry, and ACME entries showing whether anything will actually renew them.

Services

HAProxy frontends and backends, and which backends would notice a dead server.

System

Notices, installed packages and firmware with an update check, dynamic DNS, CARP status.

Building it

The project is SwiftUI, targets iOS 17, and uses XcodeGen so there is no .xcodeproj in version control. Clone it, run make project, set your development team, and build. The widget is a second target and needs an App Group, which is declared in the entitlements files.
